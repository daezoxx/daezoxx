# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

`daezoxx/daezoxx` — a GitHub **profile** repository. `README.md` renders on
<https://github.com/daezoxx>. There is no build, no test suite, and no dependencies. The product is
one Markdown file, four hand-authored SVGs in `assets/`, and one GitHub Actions workflow.

**Verification is visual, not automated.** Local Markdown previews do not reproduce GitHub's
rendering (its HTML sanitizer, image proxy, and theming all change the result). To check an SVG
before pushing, render it headlessly:

```bash
chrome --headless --disable-gpu --no-sandbox --window-size=1000,2050 \
  --screenshot=out.png file:///path/to/preview.html
```

## The constraint that shapes everything

GitHub's Markdown sanitizer strips inline `<svg>` and all JavaScript. CSS `@keyframes` **do** survive
when the SVG is a separate file referenced as an image:

```html
<img src="./assets/hero.svg" alt="..." />
```

Inlining an SVG or adding JS silently kills the animation. Wrapping stat images in `<a>` anchors has
broken rendering here before (commit `d9108db`), as has Markdown `![]()` syntax for these cards
(`abdb8a4`) — use HTML `<img>`.

Images intentionally carry **no `width` attribute**. GitHub applies `max-width: 100%`, so the
intrinsic size (900px for panels, 495px for the streak card) governs desktop while mobile scales down
automatically.

## Asset invariants

Four assets, each with one job. Do not add a fifth that repeats a biography.

| File | Purpose | Intrinsic size |
| :--- | :--- | :--- |
| `hero.svg` | Identity, positioning, signal strip | 900×240 |
| `regulatory-intelligence-architecture.svg` | Retrieval lifecycle + cross-cutting concerns | 900×640 |
| `engineering-console.svg` | Failure modes → controls | 900×352 |
| `streak.svg` | Contribution streak — **generated, do not hand-edit** | 495×195 |

Rules that the current assets satisfy and edits must preserve:

- **Never animate from `opacity: 0`.** A previous asset (`terminal.svg`) revealed text from zero, so
  all its content vanished when animation did not run. Animate between visible states only, and
  include `@media (prefers-reduced-motion: reduce)`.
- **Minimum 9.5px text, and no text below ~3:1 contrast.** Removed assets used `font-size="6"` at
  `fill="#224455"` — effectively invisible.
- **System font stacks only** (`ui-monospace, SFMono-Regular, Menlo, Consolas, …`). No external fonts;
  they will not load through the image proxy.
- `width`/`height` must equal the `viewBox` dimensions.

Text fit is checkable without a browser — monospace advance is `0.6 × font-size + letter-spacing`.
Multiply by character count and compare against the containing `<rect>`.

## Design system

Four accents, no more. Text colors are not accents.

| Token | Hex | Use |
| :--- | :--- | :--- |
| Cyan | `#22D3EE` | Primary accent, acquire stage, structure |
| Violet | `#A78BFA` | Index and retrieve stages |
| Gold | `#F0B429` | Reason/decide, warning semantics |
| Green | `#34D399` | Provenance, verified, controls |
| Void / Surface | `#080B16` / `#0B1020` | Backgrounds |
| Hairline | `#1E2A44` | Borders, rules, grid |
| Text / Muted | `#E6EDF3` / `#8FA3BF` | Primary and secondary text |

The same hex values are passed to shields.io badges (`labelColor=0B1020`) and to the streak workflow's
`options` string, so a palette change means updating all three places.

## Accessibility

Text inside an SVG loaded via `<img>` is invisible to screen readers, and at GitHub's mobile width a
900px diagram scales to roughly 4–5px text. Both problems have the same mitigation: **every `<img>`
alt attribute transcribes the full content of its SVG**, and the architecture diagram is followed by a
one-line text version of the pipeline. When you edit text inside an SVG, update its alt text in the
same change.

## The streak card

`assets/streak.svg` is generated by `.github/workflows/streak-stats.yml` and committed by
`github-actions[bot]`. Do not edit it by hand — the next run overwrites it.

The card is **not** fetched from `streak-stats.demolab.com` at page-view time. That endpoint answers
in 10–17s, far past the timeout GitHub's camo image proxy allows, so camo served and cached a failure.
The workflow uses `DenverCoder1/github-readme-streak-stats@v1.7.0`, a composite action that renders
the SVG on the runner, and commits it only when the bytes change. Card styling lives in the
single-line `options` query string — keep it on one line, since YAML folding would inject spaces into
the values.

`GITHUB_TOKEN` covers public contributions. Private contributions need a PAT with `read:user`.

## External dependencies

Only two remain, both verified reachable: shields.io badges and
`github-readme-activity-graph.vercel.app`. Prefer repository-local or Actions-generated assets over
adding a third. If a widget starts failing, replace the provider rather than debugging the URL, and
carry the palette query params across.

## Git workflow

Work on a `dev` branch and merge to `main` via pull request (`#1`–`#5` in history). Commit subjects are
imperative and describe the user-visible change.
